# PWA 质量清单

按任务范围选用，不因普通页面变更引入新缓存、账号或同步体系。

## 配置与安装

- 定位实际 manifest 来源、构建集成、Service Worker 生成配置或源码、注册、更新提示与图标。
- 不假设使用 Vite、固定插件或文件名，沿用现有实现。
- 核对名称、语言、启动地址、作用域、显示模式、主题和背景色与产品一致。
- 检查基础路径、子路径部署、深链、刷新及现有路由的兼容性。
- 核对目标平台要求的图标尺寸、Apple Touch Icon 和 maskable 资源，裁切后仍可识别。
- 图标变更使用项目已有生成流程，不假设源文件名或脚本名。
- 安装引导根据平台能力提供，不把某浏览器事件视为全平台能力。

## 缓存与更新

- 明确生成式或自定义 Service Worker，保持一套职责清晰的注册更新流程。
- 离线范围由产品决定；支持离线打开时验证应用 shell，对未缓存内容明确降级。
- 按资源性质选择策略，不无界缓存用户数据、备份或不稳定响应。
- 个性化响应明确缓存边界，检查退出登录及切换账号后旧数据隔离。
- 策略变化检查旧缓存升级清理，避免旧入口持续引用已删除的哈希资源。
- 检查生产 manifest 和 Service Worker，修复源配置，不手工修改构建输出。
- 复用更新流程，保护未提交输入，更新失败有恢复路径。

## 数据与离线

- 不预设本地优先、无需账号或所有操作离线可写，识别现有存储、认证和网络依赖。
- 离线写入仅在需求包含时实现，考虑队列、重试、重复提交及冲突。
- 数据或导入导出格式变化考虑兼容迁移，恢复/覆盖前校验并说明影响。
- 敏感数据不进入不必要的日志、URL 或缓存键。

## iOS standalone

- 核对 viewport 与安全区；使用 `viewport-fit=cover` 时正确避让边缘。
- 顶底 inset 不被布局与组件重复计算。
- 检查主滚动区、回弹、弹层背景滚动锁定和关闭后的恢复。
- 聚焦时验证键盘、视口变化、字段和底部操作，不通过禁止页面缩放损害可访问性。
- 平台 API 核对目标版本支持情况，并提供适当降级。

## 验证

运行目标项目的检查与生产构建，用已有预览方式验证生产产物。按变更检查 manifest、图标、Service Worker 注册与作用域，测试首次/重复访问、离线重开和旧版升级。涉及身份时检查账号隔离。

区分浏览器标签页与主屏 standalone，真机重点检查安全区、键盘、滚动和更新。明确未完成的浏览器、离线或设备检查，构建通过不替代运行验证。
